# V1.07.4.3｜只針對「0 候選」增加深一層匿名原因分類

2026-11-27 09:29 使用者 Windows V1.07.4.2 真實盤中掃描：25 次 REST、5 檔初篩、0 檔通過；統計顯示 3 檔因「個股即時報價不完整或過期」、2 檔因「族群方向未得到驗證」。

## 本版修正
在原本兩項統計下，額外顯示**不包含股票代碼、行情價格、單筆成交時間、API Key** 的原因與計數：

- 個股報價：交易日期／類型不符、試撮或暫停交易、最後成交時間缺失、時間格式錯誤、最後成交超過原安全門檻 90 秒、價格缺失
- 族群方向：產業欄位缺失／不適用、同產業清單無效、前一日公開資料可比較同業少於 2 檔、同業即時行情未通過、同業方向不一致或平盤

注意：「最後成交超過 90 秒」不代表 API 故障，也可能是個股或同業成交稀疏；`lastTrade.time` 是最後成交而不是每次行情更新時間。診斷僅標記，不自行放寬 90 秒門檻；更不以未知資料視為合格。

> 這是研究診斷，無正式策略推播、無委託；既有 iPhone 配對碼、V1.07.2 Windows 背景服務和 Tailscale 均不變。
