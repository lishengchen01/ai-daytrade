## 本版更新（僅研究統計）
- 在原本「五分鐘策略或當沖資格條件未全數通過」下面，針對 `evaluate()` 原有 `checks` 一一記錄 *False* 的匿名匯總次數：跳空2–4%、五分鐘K方向、影線、前五分鐘量比、VWAP、大盤及族群方向、突破回踩、券商與個股當沖資格、私人資料授權。
- 若根本未進入布林條件檢查，例如首根五分鐘K不足、行情缺平均價、K線時間錯誤，改記錄有限白名單中的「策略前置：原因」，不將任何行情欄位、金鑰、ticker、個別股票代號寫進診斷。
- **同一檔可能同時失敗多個條件，分項計數相加會大於 4；這些分項不是不同股票數，也不是勝率。**
- **不更動 evaluate() 的判斷，不放寬門檻，不開啟 Windows 背景真實訊號，不啟用券商下單；不動 V1.07.2 背景測試推播與 iPhone 配對碼。**
