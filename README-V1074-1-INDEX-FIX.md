# V1.07.4.1｜修正 Fugle 加權指數代碼識別

使用者於 2026-11-27 台股盤中 09:14 的 Windows 現場驗證，公開盤後資料 1,977 筆、初篩 5 檔正常，但因程式用名稱模糊搜尋 INDEX 清單，報錯 `ValueError: 加權指數代碼不唯一`。依 [Fugle 官方 Historical Candles 文件](https://developer.fugle.tw/docs/data/http-api/historical/candles/)：台灣加權股價指數代碼是 `IX0001`。

## 修正
- `_index_symbol` 改用官方明確代碼 `IX0001`，不再依名稱模糊搜尋。
- 每次仍以私人 Fugle API 驗證當日 `date`、`symbol`、`type=INDEX`、`exchange=TWSE`；不一致則拒絕，不會產生訊號。
- 其他自動判斷條件不變：資料時效、五分鐘K、VWAP、成交量、突破回踩、產業方向、當沖資格；不對外傳送原始行情或 Fugle Key。
- 新增錯誤指數及過期資料的離線單元測試。

## Windows 使用者更新方式
1. 從 GitHub main 下載最新程式 ZIP，解壓縮到 **新資料夾**（不要刪除已成功運作的 Windows 背景推播及 Tailscale）。
2. 在新資料夾（可看到 `v1071` 子資料夾的那一層）打開 CMD。
3. 台股盤中 09:07–13:20 執行 `py -m v1071.audit_live`，依指示在 Windows 本機確認私人授權、雙向當沖資格及輸入 Fugle API Key。
4. 檢查是否輸出掃描狀態、REST 請求數、通過條件候選數；不應再報「加權指數代碼不唯一」。
5. 若改報「IX0001 資料驗證失敗」或「無法驗證當日即時大盤方向」，提供**錯誤文字**給工程診斷，不能關閉防護或強制送出訊號。
