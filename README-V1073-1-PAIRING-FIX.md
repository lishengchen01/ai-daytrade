# V1.07.3.1｜修正 iPhone 重開 APP 後配對碼消失

## 已確認的原因與修正
V1.07.3 在訂閱成功時會另存私人伺服器網址，但已訂閱過的 iPhone 只點「發送遠端測試推播」，即使儲存配對碼成功，也未必同步儲存網址。下一次開啟 APP 時，舊邏輯只有在網址記錄與配對碼都存在且符合時才會恢復，因此可能出現「測試成功，但重開後仍須再輸入」。

V1.07.3.1：每次私人後端成功驗證配對碼（訂閱成功，或遠端測試 `sent > 0`）且本人有勾選記住時，**同時儲存網址及配對碼，並立即讀回核對**。若舊版未保存網址但已有與網址綁定的配對碼，則自動從已保存項目復原網址；仍拒絕不同網址共用配對碼。

新增「本機保存狀態」只顯示保存成功、恢復成功、尚未保存或失敗，不顯示金鑰及配對碼。

## 使用者只要做的事
1. 待新版 GitHub Pages 部署成功，iPhone 用 **主畫面圖示** 開啟智慧當沖 APP，確認上方版本 `V1.07.3.1`。
2. 最後一次輸入原本配對碼，勾選「記住這台 iPhone」，按「發送遠端測試推播」。
3. 畫面應顯示「本機保存狀態：已保存並成功讀回」；沒有出現不要認定成功。
4. 滑掉 APP 再重開；應顯示「本機保存狀態：已從此裝置恢復」，配對碼欄有遮蔽圓點。
5. 若重開後顯示「尚未保存」，手機可能清除網站資料、版本快取問題或儲存空間權限受限；請回報**狀態文字**，不要提供配對碼。

## 安全
- 不更換原本 iPhone 推播訂閱、VAPID 私鑰或配對碼，不影響 Windows 背景推播與 Tailscale Funnel。
- 僅以本人 opt-in 的本機 `localStorage` 保存敏感 bearer token；這**不是 iPhone 鑰匙圈或安全硬體儲存**，只適用於本人私人裝置。不要共用手機、截圖金鑰，或向 GitHub／ChatGPT 貼出金鑰。
- Fugle API Key 不會存入手機，正式盤中多空自動訊號仍須官方授權及策略驗證。
- 依照自動流程，更新 `main` 的 PWA HTML/JS/SW 時使用 GitHub Pages deploy workflow，沿用已有的 `quotes.json`；不重新取得原始行情或改動策略。
