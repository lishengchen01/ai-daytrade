# V1.07.3｜iPhone 可選擇記住私人推播配對碼

## 需求與範圍
原 V1.07.1 主畫面 PWA 只有 `private-push-service-v1071` 網址儲存，配對碼欄位在每次重新開 APP 時均空白。
新版本提供**可選擇的本機記住配對碼**，不會儲存 Fugle API Key，不會影響 V1.07.2 Windows 背景服務、不會自動下單、不會解除真實行情訊號授權安全限制。

## 使用方法
1. 先確認 GitHub Pages 已部署此版本；iPhone 從「智慧當沖」主畫面圖示開啟，不需重新安裝。
2. 在 V1.07.1 私人推播區段填入原先私人服務網址和原配對碼。
3. 勾選「記住這台 iPhone 的私人推播配對碼」。
4. 點「發送遠端測試推播」（已訂閱裝置即可）或「訂閱私人遠端通知」。後端成功驗證後，才將配對碼連同對應 HTTPS 服務根網域儲存在**此裝置、此網站原始來源的 localStorage**。
5. 完全關閉再重新打開 APP，預期配對碼會自動填入，核取方塊仍勾選；可直接按「發送遠端測試推播」驗證。
6. 不想記住：取消勾選即刪除已儲存資料；「忘記這台裝置的配對碼」會同時清空欄位，**不會取消原本的 iPhone Web Push 訂閱**。
7. 「取消私人推播訂閱」成功時也會清除配對碼；換私人伺服器網址會清空舊的配對碼，防止向其他伺服器誤傳。

## 隱私及安全
- 本功能是 opt-in 的 **localStorage**，不是 iOS 鑰匙圈，也不是加密密碼管理器。存於本機網站資料；同原始來源 `lishengchen01.github.io` 的腳本理論上可讀取。只有本人可信任、不與別人共用的手機才應啟用；共用裝置請勿勾選。
- 配對碼是遠端推播後端的 bearer token，應視為敏感密碼。即使不包含 Fugle Key，仍不建議截圖、分享、發佈或上傳 GitHub。
- 配對碼不隨 GitHub Pages 頁面更新、部署或任何 POST 以外要求上傳 GitHub；只有向原本私人伺服器以 Authorization 標頭傳送。
- iOS 刪除 APP、清除網站資料、重新安裝或不同裝置，仍可能需要重新填入。
- 已訂閱的 Apple Web Push 可在 APP 關閉後接收**測試通知**；配對碼記住功能不是啟用真實多空訊號。
- 真實 Fugle 多空訊號在官方授權與盤中策略驗證完成前仍保持關閉。

## 自動測試
`node tests/test_remember_pairing.cjs`：
- 預設不儲存
- opt-in 後須伺服器成功驗證才儲存
- 重新開 APP 自動恢復
- 取消記住立即移除本機儲存
- 忘記配對碼不取消通知訂閱
- 服務回應 `sent:0` 不儲存
- 換伺服器網址不帶出其他服務的配對碼

部署前請確認 GitHub Actions `V1.07.3 Remember private iPhone pairing` 為綠燈。
