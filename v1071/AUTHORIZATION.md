# V1.07.1 私人自動多空通知：授權與一鍵啟動

## 目前狀態
- Fugle API 已由使用者在 Windows 成功讀取 2330 當日 266 根分 K；這不等於全部盤中訊號均已驗證。
- iPhone 曾成功收到 Windows 服務透過 Apple Web Push 發送的測試通知。
- 使用者確認券商帳號已開通先買後賣和先賣後買現股當沖資格。
- **待確認**：Fugle 對「僅推送本人手機的私有衍生多空訊號」的明確授權與任何額外費用。

## 收到明確許可後（在 Windows 私人環境）
1. 保留原本 `%USERPROFILE%\.ai-daytrade-private\` 的配對碼、VAPID 私鑰及 SQLite 訂閱資料；勿公開或覆蓋。
2. 此 PR 通過驗證、合併後，在 Windows 更新專案；雙擊專案根目錄 `START-LIVE-WINDOWS.cmd`。
3. 僅在 **Fugle 明確確認允許上述衍生訊號推送給本人** 時，才輸入 `LICENSED`；否則直接 Enter，程式停止且不發正式訊號。
4. 首次於本人電腦確認雙向現沖資格，輸入與原本服務相同的 VAPID 聯絡 Email，以及 Fugle 金鑰（隱藏輸入、不存檔）。私人 config 只存雙向資格旗標，不包含金鑰。
5. 程式會檢查既有 iPhone 訂閱、VAPID、配對碼及伺服器；若後端未啟動，會在 127.0.0.1:8787 啟動。掃描器只在正常交易時段從真實 API 讀取資料並依原策略判斷；任何驗證條件不足皆 WAIT。
6. 若手機需要遠端開啟 APP 管理訂閱，既有 Tailscale Funnel HTTPS 必須運作。Windows 關機或休眠，掃描停止。

## 明確安全界線
- 仍使用 `v1071.scan_loop`、`scanner.py`、`strategy.py` 原先條件，不改開盤 2–4%、五分鐘K、10% 量比、VWAP、大盤／族群、突破回踩及雙向現沖資格。
- 不向 GitHub、手機端或公開網站放置 Fugle API Key、配對碼、訂閱端點、原始報價或分 K。
- 不是下單程式，沒有交易委託權限。
- 上述測試和程式修改都不構成 Fugle 使用授權，正式衍生訊號推播必須收到官方明確確認。
